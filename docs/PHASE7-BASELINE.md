온라인 서버·방·실시간 참가·비밀 투표·토큰 재접속은 시작 시 MISSING이었다. 기존 `state.transition`은 인간 1명의 행동 직후 AI 5명을 실행하며 `isHuman`도 첫 좌석에 고정되어 있었다. 따라서 온라인에 그대로 호출하면 다른 실제 참가자의 행동을 기다릴 수 없다.

확장 방향: 기존 단일 행동·관찰·정산·승패 함수를 공유하고 온라인 전용 배치 전이를 추가한다. 서버만 전체 상태와 난수를 보유하며, 브라우저에는 개별 `viewFor` 결과를 추가 필터링해 보낸다. 기존 시드와 `runId`에는 재현 정보가 포함되므로 온라인에서는 시드를 제거하고 암호학적 무작위 실행 ID를 사용한다. 싱글플레이 저장 어댑터는 온라인 상태를 거부한다.
