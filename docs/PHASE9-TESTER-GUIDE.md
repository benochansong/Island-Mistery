# ISLAND MYSTERY — BETA 0.9.0 참가 안내

여섯 명이 외딴섬에서 최대 3일을 보냅니다. 다섯 생존자는 탈출을 준비하고, 한 공작원은 정체를 숨기며 방해합니다. 현재 버전은 **Windows PC의 로컬·제한된 테스트용**입니다. 정식 출시판이나 운영 중인 공개 인터넷 서비스가 아닙니다.

## 처음 실행하기

1. Windows용 Node.js 24를 설치합니다. 최소 버전은 22.13입니다. 설치 후 열려 있던 터미널은 다시 여세요.
2. 제공된 `island-mystery-beta-0.9.0.zip`을 빈 폴더에 풀어 주세요. 압축파일 안에서 직접 실행하지 마세요.
3. `start-beta.cmd`를 더블클릭합니다. 처음에는 필요한 프로그램 구성요소를 내려받으므로 인터넷이 필요합니다.
4. 검은 서버 창을 열어 둔 채 브라우저에서 **http://127.0.0.1:4178**을 엽니다.
5. 위쪽에 **BETA 0.9.0**이 표시되는지 확인합니다. 끝낼 때는 서버 창에서 Ctrl+C를 누르세요.

이 주소는 같은 PC에서만 작동합니다. 다른 사람에게 보내도 공개 서버로 연결되지 않습니다. 외부 테스터 초대와 공개 배포는 아직 시작하지 않았습니다.

## 혼자 플레이하기

**10단계 시작 안내**를 읽거나 바로 **새로운 기록 시작**을 누르세요. 안내는 언제든 닫을 수 있고 완료할 필요도 없습니다. 이미 저장된 게임이 있다면 **이어하기**를 사용하세요. 새 게임을 덮어쓰기 전에는 확인 창이 나옵니다.

- **아침:** 지도에서 해안·정글·연구소·통신탑 중 하나를 선택하고 탐험 버튼을 누릅니다. “탐사 계획에 기록”만 누르면 탐험한 것이 아닙니다.
- **낮:** 물자 확보, 치료, 시설 수리, 연구 중 가능한 행동을 선택합니다. 나의 비밀 임무도 확인하세요.
- **토론:** 발언 목록을 펼쳐 단서 공유, 의혹, 해명, 반박 등을 선택합니다. 근거가 없으면 판단을 유보할 수 있습니다.
- **투표:** 후보를 고르고 확인 창에서 확정합니다. 기권할 수 있고 동률이면 추방하지 않습니다.
- **밤:** 직업 능력이나 휴식을 사용하고 **하루 정산**을 누릅니다. 사망하거나 추방되면 관전으로 끝까지 진행할 수 있습니다.

식량과 식수는 밤에 활동 인원당 각각 1개가 필요합니다. 부족하면 체력이 줄어듭니다. 통신탑 18 또는 보트 14를 완성하면 탈출할 수 있습니다. 공작원을 추방한 뒤 그날 밤까지 버티는 구조 승리도 있습니다. 3일째 밤까지 탈출하지 못하거나 생존자 진영이 붕괴하면 공작원이 승리하며, 전원이 사망하면 생존 실패입니다. 엔딩 화면에서 정확한 결과와 자신의 목표 달성 여부를 확인하세요.

## 같은 PC에서 온라인 시험하기

Chrome와 Firefox처럼 서로 다른 브라우저 또는 독립 시크릿 창을 사용합니다. 같은 브라우저의 일반 탭은 참가자 토큰을 공유하므로 다른 사람처럼 접속할 수 없습니다.

한쪽에서 **온라인 멀티플레이 → 방 만들기**, 다른 쪽에서 **방 코드 참가**를 선택하세요. 모두 준비하면 방장이 시작합니다. 사람 2~6명이며 빈자리는 AI가 채웁니다. AI를 끄면 사람 6명이 필요합니다. 온라인에서는 모두 행동을 제출하거나 제한 시간이 지나면 서버가 다음 단계로 이동합니다.

토론 중 자유 채팅은 다른 사람에게 전달됩니다. AI는 선택형 발언과 공개 행동을 참고하며 자유 채팅의 의미를 완전히 이해하지 않습니다. 토론 안내나 설문을 열어도 온라인 시간은 계속 흐릅니다.

대기실에서 연결이 끊기면 기본 120초 동안 자리를 보관합니다. 기한이 지나면 다시 참가하세요. 진행 중 게임은 기존 자리와 직업을 유지하고 미제출 행동은 제한 시간에 따라 처리합니다. 방장이 끊기면 다른 참가자가 방장이 될 수 있습니다. 끝난 뒤 현재 방장이 **재대결 준비**를 누릅니다.

## 의견과 오류 보내기

위쪽 **베타 의견·오류 신고** 또는 엔딩의 **플레이 평가**를 누릅니다. 설문은 선택사항이며 참여하지 않아도 게임과 보상에 불이익이 없습니다.

설문은 규칙, 탐험, AI, 추리, 긴장감, 그래픽, 소리, 조작, 속도, 재플레이 의향의 10항목을 1~5점으로 평가합니다. 오류 신고에는 발생한 문제와 재현 순서를 적어 주세요. 개선 제안도 별도로 남길 수 있습니다.

**자동으로 개발자에게 전송되지 않습니다.** 안내를 읽고 동의하면 이 브라우저에만 저장됩니다. 아래에서 저장한 내용을 확인하고 **JSON 내보내기**로 파일을 내려받아, 추후 합의한 전달 방법으로 직접 보내세요. 파일을 만들었다는 사실만으로 접수가 완료된 것은 아닙니다. 누구에게도 자동 초대나 메시지를 보내지 않습니다.

저장 내용은 작성한 의견·점수, 버전, 싱글/온라인, 날짜/단계, 종료 여부, 브라우저 종류, 화면 크기입니다. 선택하면 이번 실행의 오류 종류와 단계도 포함합니다. 자동으로 토큰·비밀번호·채팅·역할·게임 전체 저장·원본 오류 메시지·스택·접속 URL을 넣지 않습니다. 자유 의견에도 개인정보나 비밀 정보를 직접 적지 마세요.

최대 50개를 30일 동안 보관하며 기한 후 다음 접속/조회에서 삭제합니다. **의견 전체 삭제**는 피드백만 지우며 게임 저장과 성장 기록은 유지합니다. 내보낸 파일은 직접 관리·삭제해야 합니다. 다른 PC의 피드백을 자동 수집하는 서버는 없습니다.

## 자주 생기는 문제

| 문제 | 확인할 내용 |
| --- | --- |
| 창이 열리지 않음 | Node.js 설치 여부와 22.13 이상인지 확인 |
| 패키지 설치 실패 | 첫 실행에 인터넷 필요. 실패 메시지를 남겨 주세요 |
| EADDRINUSE | 이미 실행된 베타 서버 창을 확인하고 하나만 사용 |
| 온라인 연결 불가 | 서버 창을 닫지 말고 HTTP 주소로 접속. HTML만 열어서는 온라인 불가 |
| 이전 저장이 안 보임 | 4174와 4178은 브라우저 저장 영역이 다름. 이전 기록은 이전 주소에 보존됨 |
| 시작 버튼 비활성 | 최소 2명 모두 접속·준비. AI 금지이면 6명 필요 |
| 사건 창이 열림 | 선택지를 누르거나 포기한 뒤 다음 행동. 사건 화면은 정상 진행의 일부 |
| 소리가 안 남 | 먼저 화면을 클릭하고 설정의 음악·볼륨과 브라우저 음소거 확인 |
| 복귀 실패 | 서버 재시작, 대기실 기한 만료, 브라우저 저장/토큰 삭제 여부 확인 |
| 저장 불가 안내 | 시크릿 모드·브라우저 저장 권한·디스크 용량 확인. 원본 저장은 자동 삭제하지 않음 |

## 테스트 종료와 알려진 제한

정상 엔딩을 확인한 뒤 원하면 평가를 남기고 서버를 종료하세요. 미완료 게임을 포기하면 완료 보상은 없습니다. 온라인 진행 방은 서버 종료 후 사라지지만 완료한 게스트 전적·XP는 베타 전용 DB에 남습니다. 게스트 토큰을 잃으면 같은 기록에 복귀할 수 없고 계정 복구 기능은 없습니다.

PC Chrome·Edge·Firefox와 Android 크기 에뮬레이션을 검사했습니다. 실제 Android 기기, 실제 iPhone Safari, 외부 인터넷·공개 HTTPS, 장시간 부하와 실제 사용자 만족도는 아직 검증하지 않았습니다. 글로벌 랭킹은 비활성이고 로컬 게스트 기록만 제공됩니다. 경쟁 밸런스는 실제 사람의 추가 평가가 필요합니다.
