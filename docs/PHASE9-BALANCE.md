## 정책과 측정

기본 EASY 200, NORMAL 400, HARD 200, 특별 도전 200회. 도전은 여섯 모드를 순환하고 난이도도 순환한다. 최종 인간 공작원 155회, AI 공작원 845회다. 인간 자동 정책은 시드 인덱스에 따라 AI 기본 판단, 탈출 수리 우선, 증거/연구 우선, 치료/물자 우선을 순환한다. 짝수 인덱스 인간 공작원은 파괴·물 은닉·거짓 알리바이·기권을 우선하고, 나머지는 동일한 개인 공개 범위 AI 판단을 사용한다. 사건 선택은 활성 선택지의 인덱스를 순환한다. 선택지를 승리 결과를 미리 보고 고르지 않는다.

각 전이 후 전체 상태 검증과 JSON 저장 왕복, 날짜별 정산 유일성, 종료 조건과 종료 후 잠금, 같은 ACT 재전송의 거부/불변, XP 재정산 중복을 검사했다. AI 입력에는 타인의 역할·기억 및 전체 secrets/facts/progress 접근을 거부하는 Proxy를 적용했다. 실패 시 시드·단계·스택과 상태 파일을 기록하도록 구현했으며 이번 실패는 0건으로 실패 시드 재실행 대상이 없었다.

## 합리적 보완과 한계

기존 공작원은 시설의 65% 진척 또는 마지막 날까지 기다리는 동안 공개 부품으로 같은 라운드에 탈출할 수 있는 상황에서도 협력했다. 이제 다른 활동 인원과 공개 부품·수리 진척으로 한 라운드 탈출 가능성을 보수적으로 계산하고 방해를 우선한다. 다른 인물의 직업은 읽지 않는다.

같은 시드·정책의 EASY 첫 100회는 변경 전 생존자 93/공작원 7에서 변경 후 생존자 87/공작원 13으로 바뀌었다. 통계적 유의성이나 모든 환경의 개선을 주장하지 않는다. 전체 생존자 승률은 95%로 여전히 높다. 증거 활용이 강한 NORMAL/HARD에서 공작원 추방 빈도가 높고, 생존자 5명의 공동 수리·물자 공급, 자동 인간의 합법적 효율 행동도 영향을 준다. 목표 승률에 맞추어 숨겨진 보너스·불법 정보 접근·임의 결과를 넣지 않았다. 경쟁 서비스의 공정성은 미확정이며 폐쇄 테스트에서 실제 사람의 전략·토론·진행 속도를 수집해야 한다.

AI는 성격·난이도별 증거 가중치, 기억, 반박과 해명, 근거 있는 투표를 유지한다. 이번 1,000회에서 불법 AI 판단 0건, 비밀 접근 0건, 근거 없는 AI 확정 투표 0건이다. 발언은 실제 기록·개인의 믿음·명시적 거짓 알리바이로 구성된다. 자유 채팅 의미 분석과 자연스러움의 실제 사용자 평가는 하지 않았다.
