## 5. 새롭게 추가한 스토리 분기

- **1일차:** 첫 탐험에서 안내문을 발견하고 초기 생존 사건과 단서를 얻습니다. 목표·직업·초기 관계·일부 단서 위치가 새로 배정됩니다.
- **2일차:** 실험 문서·명단·출입 기록을 확보하고 공개/보관/위임으로 정보와 관계가 갈립니다. 발전기 재가동은 숨겨진 문 기회를 열고, 분해하면 해당 후속 사건을 차단합니다. 문서 사건을 포기하면 그 연결을 얻지 못하지만 다른 개방 경로는 남습니다.
- **3일차:** 선행 분기를 충족한 마지막 기록 사건 또는 연구 기록 조사로 남은 증거에 접근합니다. 절차서·명단·사고 기록을 모두 공개하면 최종 기록을 연결하므로 희귀 사건만을 기다릴 필요가 없습니다.
- **숨겨진 탐험:** 지하실·관측소·동굴·장비실은 원래 지역 반복 탐험과 사건 선택으로 개방하며 자원·기록·함정이 적용됩니다.
- **탈출 직전:** 시설 수리도가 완성 기준의 70% 이상일 때 35번 사건이 선택 후보가 됩니다. 종료 후 자동으로 단서를 주는 방식이 아니라 실제 선택으로 확인/포기합니다.

기존 조건을 달성하면 1~2일차에도 탈출합니다. 모든 이야기를 보여주기 위해 승패를 미루거나 3일을 강제하지 않습니다. 연구 조사 대체 경로는 접근 가능성을 보장하며 모든 플레이어가 반드시 진실을 수집하도록 강제하지 않습니다.

기본 A/B/C/D 승패는 `state.js`, 세부 이야기 결말은 `story.js`에서 분리합니다. 우선순위는 생존 실패 → 공작원 승리의 의혹 수준 → 추방 후 구조 → 공개된 최종 진실 → 인간의 연구 자료 → 단서 부족 → 전원/일부 귀환입니다. 엔딩에는 달성한 개인 목표와 추가 점수를 함께 표시합니다.

## 8. 발견된 오류와 수정 내용

- 공개 사건에서 개인적으로 확보한 단서까지 모두 공유될 수 있는 경계를 수정했습니다. 사건 공개 여부와 단서 공유 여부를 별도로 처리합니다.
- 소문/충돌 사건이 허구의 증언을 만들지 않도록 실제 공개 주장과 같은 시간대의 동선을 조건으로 사용합니다. 불확실한 전언을 직접 증거로 승격하지 않습니다.
- 숨겨진 장소·기록 조사 행동은 실제 부모 지역/야영지 동선으로 기록하여 이후 관찰·반박과 맞춥니다.
- 선택 대기 중 다른 행동, 중복 선택, 비용 없는 반복 자원 획득을 상태 전이에서 차단하고 이어하기에서도 선택 인스턴스를 보존합니다.
- 35번 사건을 종료 후 자동 처리에서 탈출 준비 중 선택 사건으로 옮겼습니다. 최종 200회와 Chrome 3회를 변경 후 다시 실행했습니다.
- 엔딩 상세 데이터 검증과 저장 이전을 보완하고 생존·활동·추방 명단을 구분했습니다. 이전 저장에 없던 과거 관찰을 임의로 만들지 않습니다.

## 9. 현재 남은 문제점

- **밸런스:** 이번 인간 정책과 보통 난이도에서 생존자 승률 92.5%로 편향되어 있습니다. 기능적 완주와 대등한 승률은 별개이며 공작원 전략·시설 진행·자원 공급의 조정이 필요합니다.
- **희귀 콘텐츠 노출:** 사건 22·26·36은 200회 자연 발생 0회입니다. 조건부 실행은 정상이나 실제 플레이의 발견 빈도는 추가 조정 대상입니다. 생존 실패와 의혹이 높은 공작원 승리도 자연 발생하지 않았습니다.
- **검증 범위:** 쉬움·어려움의 대규모 밸런스 실험, Firefox/Safari, 실제 모바일 기기, 장시간 수동 재미 평가는 수행하지 않았습니다. Chrome의 좁은 화면 검사는 실제 휴대폰 검사와 다릅니다.
- **AI와 저장:** 규칙 기반 AI이고 자유 입력 언어 모델은 아닙니다. 로컬 단일 플레이의 개발자 도구/저장 파일 자체를 암호화하지 않으며 여러 탭 동시 변경을 동기화하지 않습니다. 도감은 최근 1,000회 실행 ID를 보관합니다.
- **연출:** 기존 2D 화면과 텍스트 중심이며 고급 3D·음성·대형 애니메이션은 구현하지 않았습니다. 이는 이번 요구 범위 밖입니다.

## 10. PHASE 5 진입 가능 여부

**기능 개발의 기반으로 진입 가능합니다.** 기존 진행을 유지한 상태에서 요구한 36사건·12목표·4장소·기억/정보 연동·세부 결말·도감·저장 및 실제 완주 검증을 마쳤습니다. 출시 품질이나 밸런스가 완성되었다는 뜻은 아닙니다. 다음 단계에서는 위 생존자 편향과 희귀 콘텐츠 접근성, 수동 플레이 경험 및 브라우저 범위를 우선 개선하는 것이 적절합니다. Phase 5 자체는 이번 작업에서 개발하지 않았습니다.
