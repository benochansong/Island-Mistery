# BETA 0.9.0 개발·운영 안내

## 범위와 환경

외부 배포·공개 테스트·외부 테스터 초대는 별도 명시적 승인 후 수행한다. 이번 버전은 로컬 제한 테스트용이며 Phase 10 정식 출시를 수행하지 않는다. 런타임 Node.js 22.13 이상, 검증 환경은 Windows의 Node.js 24.14.0이다.

| 환경 | 실행 | 기본 주소 | 서버 저장 |
| --- | --- | --- | --- |
| 개발/기존 | `npm start` 또는 `start-online.cmd` | 127.0.0.1:4174 | `data/profiles.sqlite`, local |
| 로컬 베타 | `npm run start:beta` 또는 `start-beta.cmd` | 127.0.0.1:4178 | `data/beta/profiles.sqlite`, beta |
| 자동 QA | 테스트 내 임의 포트·격리 DB | loopback | 메모리/별도 test 파일, 출시 패키지에서 제외 |

`start-beta`는 개발용 `.env`를 읽지 않으며 loopback·베타 포트/DB/데이터셋을 지정한다. `APP_ENV=beta`는 서버 설정에서도 loopback과 beta 데이터셋을 요구한다. 환경 변수를 직접 설정할 경우 `PROFILE_DB`를 실사용 저장소에 겹치지 않게 지정한다. `PROFILE_DATASET` 오타는 실패한다.

`APP_DOMAIN`/`APP_ORIGIN`은 중앙 설정에서만 읽는다. 운영은 HTTPS 원점 필수이며 주소를 설정하는 것만으로 공개 서버가 배포되지는 않는다. 현재 DNS·등록기관·인증서·운영 라우팅은 변경하지 않았다. 추후 변경 전 실제 도메인 만료와 활성 Cloudflare 네임서버를 확인한다.

## 데이터와 개인정보

브라우저의 기존 v4 게임, 성장, 설정, 도감 키를 삭제하거나 변경하지 않는다. 베타 피드백은 별도 `island-mystery.feedback.v1` 키다. 포트가 다르면 브라우저 저장 영역도 다르므로 기존 사용자는 4174 기록을 그대로 유지한다. 자동 데이터 복사는 하지 않는다.

피드백은 선택 동의 후 로컬 저장만 한다. 최대 50개·30일 보관, 다음 조회 시 만료 삭제, 사용자 직접 삭제·JSON 내보내기를 지원한다. 외부 접수/분석 서버·계정·연락처 수집은 없다. 익명 통계로 외부 전송하는 코드도 없다. 오류 진단은 메모리에서 종류/단계 최대 20개만 보유하며 별도 선택 동의 시 저장한다. 원본 오류 메시지·스택·URL·토큰·채팅·개인/타인 역할을 수집하지 않는다. 내보낸 파일의 공유·보관은 작성자가 결정한다.

서버 전이 오류 로그는 `code`, 무작위 오류 ID, 날짜와 단계만 출력한다. 원본 예외/방 코드/토큰/역할/채팅은 출력하지 않는다. 상태 이상 방은 안전하게 진행을 중단하고 새 방 안내를 한다. 자동 복원 기능이라고 주장하지 않는다.

## 백업과 롤백

보존된 이전 안정 소스는 `d95aab6031bc6b8e9cbb7d6907c684caa915780c`이다. `.git`, `data`, `.env`, 브라우저 저장은 ZIP에 포함하지 않는다.

1. 온라인 참가자에게 종료를 알린 뒤 서버 창 Ctrl+C로 종료한다. 진행 방은 메모리에 있으므로 복원되지 않는다.
2. `data/beta/` 전체를 별도 안전한 위치에 복사한다. 서버가 실행 중일 때 SQLite 본체 파일만 복사하지 않는다. WAL/SHM 파일이 있으면 함께 보관하거나 SQLite 백업 절차를 사용한다.
3. 현재 소스와 브라우저 프로필을 보존하고 이전 안정 소스를 **별도 폴더**에 체크아웃한다. `git reset --hard`나 데이터 폴더 일괄 삭제를 복구 절차로 사용하지 않는다.
4. 이전 폴더에서 `npm ci --omit=dev`를 실행한다. 필요 시 복사한 DB를 `PROFILE_DB`로 지정해 격리 환경에서 읽기·완료 전적을 확인한다. 0.9.0은 Phase 8 DB 스키마를 바꾸지 않았다.
5. 포트를 통일해야 같은 브라우저 오프라인 저장에 접근한다. DB만 복사해도 브라우저의 게스트 토큰이 함께 복구되는 것은 아니다.

실제 패키지 테스트는 초기 실행과 전적 저장소 분리를 확인한다. 장시간 운영 장애 복구·외부 인프라 복구 훈련을 수행했다고 주장하지 않는다.

## 빌드와 재현

저장소 개발 환경에서 `npm ci`, `npm test`, `npm run test:online`, `npm run test:simulation:beta`를 실행한다. 시뮬레이션은 1,000개 고정 시드와 문서화된 정책을 사용하며 실제 인간 평가가 아니다.

`npm run build:beta`는 `releases/island-mystery-beta-0.9.0.zip`을 만든다. 서버/클라이언트/실제 에셋/패키지 잠금/시작 스크립트/테스터 문서만 명시적 허용 목록으로 포함한다. 파일별 SHA-256과 크기는 ZIP 내부 `RELEASE-MANIFEST.json`, ZIP 전체 해시는 저장소 `docs/phase9-build.json`에 기록한다. 같은 이름의 기존 폴더·ZIP은 덮어쓰지 않는다. 재빌드는 기존 아티팩트를 보존한 뒤 버전을 올리는 것이 기본이다.

브라우저 QA는 Playwright와 Chrome/Edge/Firefox가 필요하다. iOS Safari와 물리 Android는 이번 환경에 없으며 별도 장비에서 점검해야 한다. 에뮬레이션을 물리 기기 결과로 바꾸어 보고하지 않는다.

## 공개 테스트 전 추가 게이트

명시적 승인, HTTPS/WebSocket 호스팅, 운영 계정/토큰 복구 정책, 데이터 보관·백업, 요청 제한과 프록시 IP 처리, 실기기/외부 회선, 동시 부하, 실제 인간 밸런스 평가가 남아 있다. 글로벌 랭킹·상용 계정 서비스·대규모 부정행위 방지·정식 출시 인증은 현재 범위가 아니다.
