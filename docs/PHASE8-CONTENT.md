# Phase 8 콘텐츠 및 측정 조건

업적 진행은 실제 행동 지점에서 기록하고 정상 종료 때 확정한다. 진행 중 수치는 공개 랭킹으로 보내지 않는다. 자기 치료는 협력 실적에서 제외하고, 동일 단서·같은 증거·이미 완료한 경기 ID를 중복 정산하지 않는다. 누적 업적은 여러 경기의 합계이며 새 경기마다 초기화되지 않는다.

탐험 성공은 물자 획득 판정 성공이다. 해안 희귀·연구소·중요 단서 실적에서 첫 안내문은 제외한다. 같은 스토리 단서는 한 경기에서 한 번만 발견 실적으로 인정하며 다른 사람이 공개한 단서를 받은 경우는 직접 발견으로 세지 않는다. 공작원 추방 기여는 실제 단독 최다 득표로 추방된 날 그 대상에게 투표한 사람만 인정한다. 시설 기여 XP와 기술자 업적은 실제 탈출을 완성한 시설에 자신의 복구 기록이 있어야 한다. 모순은 직접 증거와 모순으로 판정된 서로 다른 발언 ID다. 정보 조작은 공작원의 전가 발언을 들은 다른 인물이 자기 증거 없이 무고한 대상의 의심도를 실제로 올린 경우다. 완벽한 위장의 평균 신뢰는 본인을 제외한 활동 인물 기준이다.
