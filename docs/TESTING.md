# Phase 2.5 검증 및 완료 보고

검증일: 2026-11-20 (Asia/Seoul). Phase 3 개발은 중단하고 Phase 2 핵심 게임만 보완했습니다.

## 시작 진단과 수정

작업 전 백업은 `backups/pre-phase2-5-repair.zip`, 초기 기능별 진단은 [PHASE2-AUDIT.md](PHASE2-AUDIT.md)에 있습니다. 기존 테스트 최초 실행은 **6개 중 1개 통과, 5개 실패**였습니다.

직접 확인한 실행 오류는 데이터 버전 2와 상태 검증 버전 1의 불일치였습니다. 새 게임이 스스로 유효하지 않은 상태를 만들어 선택·저장이 실패했습니다. 그 외 탐험·직업·날짜·투표·엔딩은 오류가 있는 완성 기능이 아니라 **미구현 기능**이었습니다. AI 초안도 실행 경로에 연결되지 않았습니다.

다음과 같이 수정했습니다.

- 버전 2의 완전한 상태 생성·검증·저장 경계를 맞췄습니다.
- 기존 시작 화면, 지도, 계획 기록, 수색 기록, 새 게임·이어하기·확인창을 보존하고 실제 게임 규칙을 연결했습니다.
- 단계별 1회 행동과 다음 단계 조건을 단일 전이 함수에서 검증합니다. UI 버튼 상태만으로 중복 실행을 막는 구조가 아닙니다.
- 밤 정산은 `settledDays`로 하루 한 번만 허용하며 인원 감소·자원 부족을 반영합니다.
- 추방·사망 시 직접 행동을 금지하고 관전 진행을 제공했습니다.
- 모든 역할·비밀 단서를 UI에 보내지 않도록 `viewFor`로 정보를 분리했습니다. 공작원의 환경 피해는 행동자 없이 단계 말에 공개합니다.
- 버전 1 저장은 별도 키에 그대로 남기고 안내합니다. 자동으로 삭제하거나 새 역할을 임의 배정해 덮어쓰지 않습니다.
- 390px 모바일에서 자원 단위가 잘리는 줄바꿈과 지도 표식 간격을 보완했습니다.

## 실제 브라우저 검증

Node의 게임 자산 전용 로컬 HTTP 서버와 앱 내 Chromium 브라우저에서 실제 버튼을 눌러 확인했습니다. 처음에는 샌드박스 서버에 연결할 수 없어 시간 초과가 났으며, 승인된 샌드박스 밖 127.0.0.1 서버로 실행 환경을 수정한 뒤 연결됐습니다. 외부 공개 서버는 만들지 않았습니다.

**플레이 A: 인간 의사 / AI 공작원**

- 네 지역 선택, 통신탑 탐험, 개인 단서와 부품 획득, AI 5명의 탐험 확인.
- 탐험 완료 후 행동 목록은 비어 있고 다음 단계 버튼 활성화.
- 새로고침·이어하기 전후 직업·날짜·자원·탐험 결과 텍스트가 정확히 일치.
- 낮 보급 → 토론 → 기권 → 밤 휴식 → 배급 → 2일차로 이동.
- 2일차 투표·밤 정산 이후 **B 엔딩(공작원 추방 후 구조)** 완료.
- 새 기록 확인창에서 취소 시 엔딩 유지, 확인 시 1일차·초기 자원·기록 1개로 초기화.

**플레이 B: 인간 공작원**

- 일반 새 게임 재배정으로 공작원 역할을 받은 뒤 시작.
- 정글 탐험, 식수 은닉, 낮·밤 통신탑 파괴, 토론·기권 선택.
- 1일차 → 2일차 → 3일차를 모두 정상 진행.
- **마지막 밤 정산 → C 엔딩(탈출 저지 승리)** 완료.
- 엔딩 이후 행동 버튼 0개, 다음 단계 비활성화.
- 엔딩에서 새로고침·이어하기 후 같은 결과 복원.
- 개인 기록 8개와 공개 기록 190개 필터 전환 확인.
- 플레이 안내 모달 열기·닫기 확인.

## 아직 검증하지 않았거나 구현하지 않은 것

- `file://` 직접 실행은 브라우저 도구의 프로토콜 제한 때문에 실조작 검증하지 않았습니다. 런타임은 상대 경로의 고전 스크립트만 사용하며 모듈·fetch·서버에 의존하지 않습니다. 실제 확인한 실행 경로는 HTTP입니다.
- Firefox/Safari, 모바일 실기기, 모든 화면 크기, 완전한 키보드/스크린리더 접근성 감사는 수행하지 않았습니다.
- AI의 장기 기억, 검증 가능한 거짓말, 80개 이상 대사, 다단계 심리전과 고급 관계 UI는 Phase 3 보류 항목입니다. 초안이 있어도 완료 기능이 아닙니다.
- 12종 이상 사건은 최초 장기 기획의 확장 목표입니다. 이번 Phase 2에는 8종 하루 사건과 탐험 중 특별 보급 사건을 제공합니다.
- 네트워크 멀티플레이, 서버 권위 판정, 여러 저장 슬롯, 탭 간 동기화, 웹 배포는 수행하지 않았습니다.
- 밤 행동은 인간부터 좌석 순서대로 처리합니다. 완성 직후 탈출하므로 뒤 순서의 방해는 무효입니다. 동시 행동 처리와 더 정밀한 밸런스는 후속 설계 대상입니다.
