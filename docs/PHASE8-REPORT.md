# PHASE 8 개발 완료 보고

2026-11-20 기준. **로컬 게임의 성장·반복 플레이 기능과 서버 검증 영구 게스트 기록을 구현했다.** 공식 계정 체계가 없으므로 요구사항의 허용 조건에 따라 글로벌 랭킹은 비활성화하고 실제 결과만 사용하는 로컬 서버 랭킹을 제공한다. 외부 베타 운영과 공개 배포는 하지 않았다.

## A. 기존 프로젝트 상태

Phase 7 기준 커밋 `faf24efc1e847f71a7298394f7282a9caf25afeb`으로 전체 기존 프로젝트를 보존했다. [시작 진단](PHASE8-BASELINE.md)에 14개 항목의 상태와 근거를 기록했다. 기존 규칙 107개와 실제 소켓 20개가 통과했고 핵심 온라인 진행을 막는 오류는 발견하지 않았다. 결과 기록은 PARTIAL이었다. 기존 오프라인 도감은 있지만 온라인 완료 결과는 서버 재시작 시 사라졌으며, 장기 성장 시스템은 없었다.

개발 중 발견한 문제는 다음과 같이 수정했다. 정산 직후 메모리 객체와 저장 복원 객체 사이에 남던 `undefined` 필드를 제거해 재정산 결과의 일관성을 확보했다. 기존 사건 테스트의 준비 조건을 신규 후속 사건에도 맞췄다. 첫 안내문을 희귀/중요 단서 실적에서 제외했고, 탈출 기여는 실제 완성한 시설의 작업으로 제한했다. 성장 저장의 중첩 필드를 검사하고 손상 데이터를 덮어쓰지 않게 했다. 온라인 반복 임무 표시는 서버 시각을 사용한다.

진행 중인 게임의 `progress`는 행동 발생 지점의 측정 자료다. 영구 프로필은 별도 저장한다. 업적 계산은 정상 종료 정산 때 수행하며 매 프레임 30조건을 검사하지 않는다. 재시작·재접속·이전 종료 저장 열기로 중복 보상을 만들지 않는다.

XP: 완료 50, 승리 50, 성공 탐험 10/회, 직접 확보 단서 15/개, 목표 25, 공작원 추방 기여 30, 탈출 시설 기여 30. 반복 임무 XP는 별도다. 다음 레벨 비용은 `100 + 50 × (현재 레벨 - 1)`이며 레벨 30에서 멈춘다. 레벨·장식은 AI 판단이나 게임 능력치를 바꾸지 않는다.

온라인의 명시적 이탈·직접 행동 0회·미완료 경기는 보상이 없다. 일시 단절과 관전은 이전 직접 참여가 있으면 정산한다. 오프라인 미완료 게임을 포기하면 보상이 없다. 세부 규칙은 [실행·정산 안내](PHASE8-RUN.md)에 있다.

## C. 도전과제 목록

[콘텐츠 및 측정 조건](PHASE8-CONTENT.md)에 **30종 전체의 ID·이름·설명·실제 조건·목표·숨김 여부·보상**을 표로 제공했다. UI에서는 진행률과 달성 날짜를 표시한다. 누적 조건은 여러 정상 종료 경기에서 합산하며, 숨김 업적 4개는 달성 전 이름과 조건을 표시하지 않는다.

희귀 단서는 이야기 단서의 직접 발견으로 정의하고 안내문을 제외한다. 타인 치료만 협력으로 세며 같은 증거 공개는 한 경기 한 번이다. 모순은 직접 증거로 판정된 발언 ID를 중복 제거한다. 공작원 전가 발언의 실제 의심 상승을 측정하며 추측을 진실 판정으로 취급하지 않는다. 팀 탐험은 같은 날·단계·지역에서 서로 탐험에 성공한 실제 결과로 인정한다.

온라인 첫 판은 인간 기술자/공작원, 재대결은 인간 조사관/탐험가와 AI 공작원이었다. 두 판 모두 두 브라우저가 엔딩 B를 확인했다. 자기 프로필과 서버 랭킹을 양쪽에서 조회해 완료 횟수와 목록 일치를 검사했다. 실제 자유 채팅·새로고침 복귀·비밀 패킷 분리·재대결도 유지됐다. [서버 기록 랭킹](phase8-online-ranking.png). 두 브라우저 시험은 한 PC에서 실행했으며 두 물리 기기·실제 휴대폰·외부 회선 시험은 하지 않았다. 실행된 브라우저의 JavaScript 오류는 0개였다.

검증 경로는 UI → 서버 요청 → 규칙 결과 → SQLite 트랜잭션 → 참가자별 응답 → 프로필/랭킹 표시다. `vercel:verification` 스킬의 전체 흐름 절차를 적용했고 서버 재시작까지 확인했다. 테스트용 저장소는 실사용 저장소와 별도 경로·데이터셋을 사용했으며 가상 전적을 랭킹에 섞지 않았다. 조건부 회귀 기록은 격리된 메모리/임시 DB에서만 생성했다.

최종 서버를 재시작한 뒤 Chrome에서 기존 테스트 랭킹 유지, 조건에 맞는 경쟁 경기 없음의 정확한 표시, 서버 시각 응답, 통신탑 추가 손상 4 안내도 확인했다. [최종 브라우저 점검](phase8-final-browser-smoke.json).

## H. 남은 한계와 미구현 범위

- **공식 계정·글로벌 랭킹은 미구현/비활성.** 현재는 토큰 기반 게스트다. 토큰 분실 복구·이메일/소셜 로그인·기기 간 계정 연결은 없다.
- 반복 구성 감지는 동일 게스트 구성의 24시간 내 네 번째 경기부터 경쟁 제외하는 초기 규칙이다. 게스트를 새로 만드는 부정행위와 담합을 완전히 막지 못한다. 이를 글로벌 경쟁 서비스라고 표시하지 않는다.
- 도전 모드는 싱글플레이 전용이다. 온라인 기본 게임과 영구 캐주얼 기록은 작동한다.
- 영구 저장은 완료 결과와 프로필이다. 진행 중 온라인 방은 여전히 메모리이며 서버 중단 시 복구하지 않는다.
- 오프라인 기기 시간·저장 데이터 조작은 신뢰할 수 없다. 글로벌 랭킹에 반영하지 않는다. Web Locks 미지원 환경의 여러 탭 동시 편집은 제한한다.
- 프로필당 영구 정산 ID 10,000개 보관 한도가 있다. UI 최근 전적은 10개다. 대규모 운영에서는 보관 정책·DB 쿼리 집계·계정 정책을 추가해야 한다.
- 이번 자동 정책에서 생존자 승률이 높다. 인간 여럿의 장기 밸런스·사용성 평가, 장시간 부하·공개 HTTPS·두 기기 검증은 남아 있다.

현재 명시한 로컬 필수 흐름에서 재현되는 미수정 진행 중단 오류는 없다. 위 제한을 숨기거나 미검증 기능을 PASS로 표시하지 않는다.

## I. 실행 방법

Node.js 22.13 이상(24 권장) → `start-online.cmd` 더블클릭 → 표시된 주소 접속. 메뉴에서 프로필·도전과제·전적·보상을 확인하고, 특별 도전은 다음 싱글플레이의 모드로 선택한다. 온라인은 방 생성/참가 후 모두 준비하고 방장이 시작한다.

설치·정산·시간 경계·토큰·DB 백업·테스트 서버 구분은 [Phase 8 실행 안내](PHASE8-RUN.md)에 설명했다. DB와 토큰을 GitHub에 올리지 않는다. 운영 도메인은 환경 변수만 사용한다.

## J. Phase 9 진입 평가

**로컬 기능 확장과 내부 검증을 진행할 수 있는 상태다. 외부 공개 베타에 즉시 준비 완료라고 판단하지 않는다.** 공개 베타를 다음 목표로 잡는다면 계정/토큰 복구, HTTPS 배포, 두 기기, 운영 백업, 동시 부하, 보안 검토, 실제 인간 밸런스를 먼저 검증해야 한다. Phase 9의 외부 베타 및 정식 출시 준비는 이번 작업에서 수행하지 않았다.
