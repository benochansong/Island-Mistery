# Phase 8 실행·기록 안내

## 시작하기

Node.js **22.13 이상(24 권장)**을 설치한 뒤 프로젝트의 `start-online.cmd`를 더블클릭한다. 최초 실행은 인터넷에서 npm 패키지를 설치한다. 터미널을 유지하고 출력된 `http://127.0.0.1:4174`를 브라우저로 연다. 종료는 Ctrl+C다. 직접 실행은 `npm ci` 다음 `npm start`다. `.env`를 직접 읽을 때는 `node --env-file=.env server/index.cjs`를 사용한다.

온라인 방과 LAN 친구 초대 방법은 [Phase 7 실행 설명서](PHASE7-RUN.md)의 주소·방화벽 안내를 따른다. 서버가 없는 `index.html` 더블클릭은 싱글플레이만 지원한다. 이번 단계에서는 인터넷 공개 배포를 하지 않았다.

## 새로운 메뉴

- **내 프로필:** 게스트 닉네임, 레벨 1~30, 누적 XP, 진영별 전적, 대표 칭호, 일간/주간 임무.
- **도전과제:** 30종의 확정 진행률과 보상. 숨겨진 업적은 달성 전 이름·조건을 숨긴다.
- **게임 전적:** 기본/특별 도전, 난이도, 인간·AI 구성, 역할별 승률·탐험 성공률, 최근 10게임.
- **랭킹:** 이 서버가 확정한 실제 완료 경기만 조회. 캐주얼/경쟁 조건 및 역할 필터. 글로벌 랭킹은 비활성화되어 있다.
- **특별 도전:** 다음 싱글플레이의 모드를 고른다. 기존 진행 중 저장은 바뀌지 않는다. 온라인은 기본 모드를 유지한다.
- **보상 및 꾸미기:** 해금한 칭호·프로필 테두리·배경·캐릭터 배지·메뉴 테마·기록 테두리를 선택한다. 능력치에는 영향이 없다.

프로필/업적/전적/꾸미기의 상단 선택창으로 **싱글플레이(이 브라우저)**와 **온라인(서버 게스트)**를 구분한다. 온라인 서버가 없으면 오류 안내를 표시하고 로컬 기록은 계속 사용할 수 있다.

## XP와 보상 규칙

정상 종료 시 기본 50 XP, 진영 승리 50, 탐험 성공당 10, 새로 직접 확보한 단서당 15, 개인 목표 25, 공작원 추방에 유효표로 기여 30, 실제 탈출한 시설 복구 기여 30을 지급한다. 반복 임무 보너스는 별도다. 이미 종료한 같은 경기 ID는 다시 지급하지 않는다. 새로고침·이어하기·재접속에도 동일하다.

기본 레벨 상승 비용은 100 XP이며 레벨마다 50 XP씩 늘어난다. 레벨 30 이후에도 누적 XP는 기록한다. 모든 성장 보상은 외형이며 게임 판정은 동일하다.

미완료 싱글플레이를 새 게임으로 덮어쓰면 그 경기의 보상은 없다. 서버가 종료되기 전 끝나지 못한 온라인 경기도 보상은 없다. 온라인에서 명시적으로 **방 나가기**를 하면 보상을 포기한다. 일시적 연결 끊김은 좌석을 유지하고, 종료 전에 직접 제출한 행동이 한 번 이상 있으면 완료 보상을 받을 수 있다. 관전자는 이전에 참여했고 방을 나가지 않았다면 정산 대상이다. 전혀 행동을 제출하지 않은 참가자는 제외한다.

반복 임무는 경기 **종료 시각** 기준이다. 일간은 UTC 00:00부터 다음 날 00:00 직전, 주간은 월요일 UTC 00:00부터 다음 월요일 직전이다. 한국 시간으로 오전 9시에 경계가 바뀐다. 미완료 경기를 여러 날에 걸쳐 플레이해도 종료한 구간에 반영한다. 같은 구간에서 각 보상은 한 번이다. 온라인은 서버 시각을 사용한다. 오프라인은 기기 시각이며 시간 조작을 완벽하게 방지하지 못한다. 이전 기록보다 과거 시각이면 반복 임무 정산을 보류한다.

## 저장 위치와 복구

| 정보 | 저장 위치 | 서버 재시작 |
| --- | --- | --- |
| 싱글플레이 진행 | localStorage `island-mystery.save.v4` | 영향 없음 |
| 기존 도감 | localStorage `island-mystery.codex.v1` | 영향 없음 |
| 오프라인 성장 | localStorage `island-mystery.growth.v1` | 영향 없음 |
| 온라인 방 복귀 | localStorage `island-mystery.online.session.v1` | 방이 사라져 무효화 |
| 온라인 게스트 접근 | localStorage `island-mystery.online.guest.v1` | 같은 SQLite를 유지하면 유효 |
| 온라인 완료 전적·XP·업적·보상 | 기본 `data/profiles.sqlite` | 유지 |

닉네임은 인증 수단이 아니다. 온라인 게스트는 추측하기 어려운 토큰으로 식별한다. 토큰을 지우거나 브라우저 저장소를 초기화하면 같은 닉네임을 입력해도 기존 프로필로 복귀하지 못한다. 이메일/비밀번호 계정, 토큰 분실 복구, 기기 간 계정 연동은 구현하지 않았다. 계정 가입이 완료되었다고 표시하지 않는다.

브라우저 주소·포트·프로필이 달라지면 localStorage도 달라진다. 같은 PC에서 두 참가자로 시험하려면 Chrome와 Firefox 또는 독립 프로필을 사용한다. 일반 탭은 게스트 토큰을 공유하며 같은 게스트는 한 방에서 한 좌석만 사용한다.

오프라인 저장은 한 JSON 쓰기로 정산 내역과 XP를 함께 보존한다. Web Locks를 지원하면 같은 출처 탭의 쓰기를 직렬화한다. 미지원 브라우저의 동시 여러 탭 편집은 보장하지 않으므로 한 탭에서 사용한다. 손상되거나 읽을 수 없는 성장 데이터는 원본을 덮어쓰지 않는다. 저장 공간 부족은 오류를 표시하고, 종료 저장이 남아 있으면 공간을 확보한 뒤 이어하기로 재시도할 수 있다.

영구 중복 방지를 위해 오프라인/게스트 프로필은 최대 10,000 경기 정산 ID를 보관한다. 한도에 도달하면 조용히 오래된 ID를 지우지 않고 정산 오류를 알린다. 최근 전적 UI는 10개, 누적 통계와 기존 업적은 유지한다. 이전 버전의 경기에는 실제 행동 측정 자료가 없으므로 엔딩·도감을 유지하고 XP를 소급 지급하지 않는다.

## 서버 운영 설정

`.env.example`의 `PROFILE_DB`로 DB 경로를 지정한다. 기본은 프로젝트의 `data/profiles.sqlite`다. DB와 `-wal`/`-shm` 파일은 Git과 HTTP 자산 제공에서 제외한다. 백업 시 서버를 정상 종료한 뒤 DB 파일을 복사한다. 실행 중에는 WAL 파일을 빼고 DB만 임의 복사하지 않는다.

`PROFILE_DATASET=local`은 로컬 게스트 경기이며, 자동 테스트 서버에는 **별도 DB 경로**와 `PROFILE_DATASET=test`를 함께 사용한다. 테스트 랭킹은 “테스트 전용 데이터”로 표시한다. 테스트를 실사용 DB에서 실행하지 않는다. 메모리 DB를 사용하는 단위 테스트는 종료 시 사라지지만 실제 서버 기본 DB는 파일에 영구 저장된다.

SQLite는 Node.js 내장 `node:sqlite`를 사용한다. 지원 환경에서 실험적 API 경고가 나올 수 있으며 경고만으로 저장 실패를 뜻하지 않는다. [Node.js 공식 SQLite 문서](https://nodejs.org/api/sqlite.html)를 참고한다. 프로필 업데이트와 경기 ID 정산은 SQLite 트랜잭션과 유일 키로 보호한다.

현재 경쟁 조건은 인간 6명, 기본 모드, 보통 난이도, 2일 이상, 각자 직접 행동 3회 이상, 명시적 이탈 없음이다. 동일 참가자 구성의 24시간 내 네 번째 경기부터 경쟁 통계에서 제외한다. 캐주얼 기록은 유지한다. 게스트를 새로 만드는 부정행위를 완전히 차단하는 계정 체계는 없으므로 **공식 글로벌 경쟁 랭킹으로 사용할 수 없다.**

운영 도메인은 기존 정책대로 `APP_ORIGIN`/`APP_DOMAIN`으로만 설정한다. 공개 배포·DNS 변경·외부 베타 운영은 이번 단계에 포함하지 않는다.

## 검증 재실행

```powershell
npm test
npm run test:online
npm run test:simulation
```

브라우저 테스트는 별도 터미널에서 테스트 전용 서버를 먼저 실행한다.

```powershell
$env:PORT='4175'
$env:PROFILE_DB=Join-Path $PWD 'data/phase8-qa.sqlite'
$env:PROFILE_DATASET='test'
node server/index.cjs
```

다른 터미널에서 `npm run test:browser:phase8`, `npm run test:browser:phase8-online`을 실행한다. 설치된 Chrome와 Playwright Firefox가 필요하다. 결과는 `docs/phase8-*`에 저장된다. 350회 시뮬레이션은 자동 정책 실행이며 사람의 플레이 승률을 뜻하지 않는다.
