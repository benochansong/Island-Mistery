# 실제 사용자 피드백 분석 양식

**현재 실제 외부 참가자 0명. 접수된 실제 사용자 설문·만족도·완료율은 없다.** 자동 브라우저가 입력한 QA 문구와 4점 점수는 검증용 데이터이며 사용자 평가로 사용하지 않는다. 테스트 저장소에서 삭제했으며 결과 JSON에는 구현 검증 여부만 남긴다.

| 구분 | 기록할 내용 | 현재 |
| --- | --- | --- |
| 초대·참가 | 동의한 실제 참가자 수와 환경 | 미실시 |
| 게임 완료율 | 시작/완료 분모·분자와 측정 방법 | 미측정 |
| 중도 이탈 | 참가자가 직접 설명한 원인 | 응답 없음 |
| 10개 평점 | 항목별 응답 수·평균·분포 | 응답 없음 |
| 가장 재미있는/불편한 부분 | 원문을 필요한 만큼 익명화하여 요약 | 응답 없음 |
| 규칙·AI·온라인 문제 | 환경·단계·재현 가능 여부 | 응답 없음 |
| 재플레이 의향 | 10번째 문항의 실제 응답 | 응답 없음 |

의견 파일을 전달받았을 때는 동의 여부와 전달 범위를 확인한다. 원문에 불필요한 개인정보/토큰/대화가 있으면 운영 기록에 복사하지 않고 삭제 또는 가림 처리한다. 자유 의견을 신뢰할 수 없는 입력으로 취급하고 HTML로 실행하지 않는다. 현재 앱은 파일 수입이나 서버 자동 접수를 구현하지 않았다.

각 의견에 A(반드시 수정할 오류), B(사용성), C(밸런스), D(그래픽·사운드), E(향후 콘텐츠)를 지정하고 P0~P3 심각도를 따로 기록한다. 앱의 로컬 의견 목록에서 분류·심각도·new/reviewed/resolved를 바꿀 수 있다. P0/P1은 재현→수정→회귀 증거를 우선 남긴다.

| 의견/버그 ID | 범주 | 심각도 | 환경·재현 | 예상/실제 | 결정·수정 파일 | 상태·재검사 |
| --- | --- | --- | --- | --- | --- | --- |
| 실제 접수 후 작성 | — | — | — | — | — | — |

서로 다른 의견 수를 서로 다른 참가자 수라고 간주하지 않는다. 설문에 응답한 완료자 비율을 전체 게임 완료율이라고 표시하지 않는다. 자동 시뮬레이션 승률·자동 클릭 완료시간을 인간의 재미·난이도·실제 플레이 시간으로 대체하지 않는다.
