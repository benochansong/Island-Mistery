## 오류와 미완성 구분

- FAIL / 논리 오류: 공작원이 일반 수리 및 사건 선택으로 상대 탈출을 완성할 수 있었다. 일반 행동의 즉시 패배 선택을 제거하고 사건 결과도 확인한다.
- FAIL / 정보 경계: 고발의 supported 표시가 발언자 비공개 voteScores에서 왔다. 청자가 이미 가진 기억으로만 판정하도록 수정했다.
- PARTIAL / 전략: 생존 위험·즉시 탈출보다 개인 임무가 우선했고 같은 점수에서 첫 좌석을 반복 조사했다. 긴급 우선순위와 제한된 동점 선택을 적용했다.
- PARTIAL / 난이도: 기존에는 증거 가중치·모순 기준만 달랐다. 관찰·기억 활용·관계 비중·판단 오차·계획을 추가했다.
- PARTIAL / 안내: 수동 도움말은 있었으나 첫 실행 안내와 상황별 설명, 간단한 결과 보기가 없었다. 기존 도움말을 재사용해 보완했다.
- PARTIAL / 사건: 22·26·36번 자연 발생 0회. 26번은 보트 선택 편향 수정, 31·36번은 조건 만족 시 가중치 조정. 22번을 거짓 조건으로 강제하지 않았다.

PASS는 명시한 기능의 실제 실행을 뜻하며, 모든 인간에게 재미있거나 완벽하게 균형 잡혔다는 뜻이 아니다.
