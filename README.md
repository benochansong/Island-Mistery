# ISLAND MYSTERY · 사라진 섬의 비밀

HTML/CSS/JavaScript로 실행하는 한국어 싱글플레이 생존·추리 게임입니다. **Phase 6: AI 추리 수준·증거 기반 투표·전략·게임 안내를 개선하고 반복 플레이와 실제 브라우저로 검증했습니다.** 인간 1명과 AI 5명이 최대 3일 동안 탐험, 물자 확보, 토론, 투표, 밤 행동을 수행하고 엔딩에 도달합니다.

기존 탐험·직업·자원·네 엔딩과 Phase 3의 성격·기억·토론을 유지합니다. 과거 초안은 `drafts/phase3/`에 보존하고 실제 기능은 `js/`에서 실행합니다. 최신 검증과 한계는 [Phase 6 결과 보고서](docs/PHASE6-REPORT.md), 사건·목표별 설명은 [콘텐츠 목록](docs/PHASE4-CONTENT.md)을 확인하세요.

## 실행 방법

`index.html`을 최신 브라우저로 여세요. 게임에는 설치, 빌드, 서버, 계정, 외부 API, 인터넷 연결이 필요하지 않습니다. 코드·SVG·스타일은 모두 로컬 파일입니다. `file://` 저장 정책은 브라우저마다 다릅니다.

실제 브라우저 검증에 사용한 HTTP 실행 방법은 다음과 같습니다. Node.js는 이 개발용 미리보기 및 테스트에만 필요합니다.

```sh
node tests/serve.cjs
```

출력된 [로컬 미리보기](http://127.0.0.1:4173)를 여세요. 이 서버는 127.0.0.1에서 지정한 게임 자산만 제공합니다. 종료는 실행 터미널에서 Ctrl+C입니다.

## 화면과 소리

- 타이틀과 지역 장면에는 실제 생성한 섬 일러스트를 사용합니다. 6명의 초상화는 기본·의심·분노·불안·놀람·부상 6상태로 바뀝니다. 직업은 그림에 고정되지 않습니다.
- 아침·낮·토론·투표·밤에 장면 색감과 음악이 바뀝니다. 지도에서 지역을 고르면 해당 지역에 맞는 배경 구도와 실제 행동 선택지가 연결됩니다. 미발견 장소는 이름과 내용을 숨깁니다.
- 토론에는 발언자 초상화와 대화창, 이전/다음 발언 및 즉시 표시가 있습니다. **공개 대사 자동 재생**은 이미 확정된 기록만 넘깁니다. **남은 토론 자동 진행**은 기존 규칙대로 인간이 판단을 유보하고 실제 AI 토론을 진행하는 별도 기능입니다.
- **설정**에서 음악·효과음 켜기/끄기, 전체/음악/효과음 볼륨, 효과 감소, 흔들림, 텍스트 속도, 대사 자동 재생, 전체화면, 초기화를 사용할 수 있습니다. 운영체제의 효과 감소도 따릅니다.
- 소리는 첫 클릭 또는 키 입력 이후 시작합니다. 9개의 12초 앰비언트 음악 루프와 16개 효과음은 직접 합성한 실제 WAV 파일입니다. 창이 가려지면 일시 정지하고, 전환 페이드와 중복 재생 제한을 적용합니다.
- 이미지·음원이 로드되지 않아도 기본 지도/이니셜과 무음으로 계속 플레이합니다. 그림·음향 출처와 제작 프롬프트는 [에셋 제작 기록](assets/PROVENANCE.md)에 있습니다.
- 연출의 건너뛰기는 게임 상태를 변경하지 않습니다. 자원·단서·투표 결과는 기존 엔진이 한 번 확정하고 화면이 그 결과를 표시합니다.

## 플레이

1. **새로운 기록 시작**을 누르고 자신의 비밀 직업과 개인 목표를 확인합니다. 선택적으로 0~4294967295의 재현 시드를 입력할 수 있습니다.
2. **아침:** 네 지역 중 하나를 선택해 실제 탐험하거나 휴식합니다. 기존 **탐사 계획에 기록**은 별도의 개인 메모 기능으로 유지했습니다.
3. **낮:** 물자 확보·치료·시설 수리·연구 기록 조사 중 하나를 선택합니다. 공작원은 은닉·파괴를 선택할 수도 있습니다.
4. **저녁:** 사건 공유 → 의심 제기 → 질문·해명 → 증거 검토 → 최종 의견의 5회 토론을 진행합니다. 발언 목록을 펼쳐 자신의 기록·단서·추측·거짓 알리바이·반박을 선택합니다. **남은 토론 자동 진행**은 나는 판단을 유보하며 AI의 실제 발언과 판단을 모두 처리합니다.
5. **투표:** 후보 버튼을 누른 뒤 확인 창에서 **투표 확정**을 누릅니다. 확정 전에는 취소할 수 있습니다. 기권할 수 있습니다. 단독 최다 득표자만 추방하고 동률이면 추방하지 않습니다.
6. **밤:** 직업 능력·치료·수리·휴식 중 가능한 행동을 선택합니다. **하루 정산**으로 배급을 처리하고 다음 날로 이동합니다.

각 단계(토론은 각 소단계)에서 인간이 한 번 행동한 뒤 활동 가능한 AI들이 좌석 순서대로 한 번씩 행동합니다. 종료 조건이 충족되면 남은 행동을 즉시 중단합니다. 아직 행동하지 않았으면 다음 단계로 갈 수 없습니다. 이미 완료한 행동은 다시 실행되지 않습니다.

추방되거나 사망한 인간 플레이어는 **관전 · 생존자 행동 진행**으로 끝까지 볼 수 있습니다. 탈락한 인물은 행동·투표·배급 대상에서 제외됩니다. 역할은 추방 시에도 공개되지 않습니다.

## 이야기와 수집

아침과 낮의 행동 처리 뒤 현재 장소·날짜·시설·실제 발언·생존 인원에 맞는 사건을 가중치로 뽑습니다. 같은 사건은 한 게임에 한 번, 전체 사건은 하루 최대 2개입니다. 인간이 참여한 사건은 2~4개의 선택 버튼으로 처리하며, 비용이 부족한 선택은 비활성화됩니다. 비용 없는 포기가 항상 있고 선택 전에는 다른 행동을 할 수 없습니다. AI가 담당한 사건은 자신이 아는 정보와 목표로 자동 선택합니다.

- 원래 네 지역을 탐험해 숨겨진 장소를 개방합니다. 발견한 장소의 부모 지역을 선택하면 아침·낮에 세부 탐험이 가능합니다. 각 인물은 장소별 한 번만 희귀 자원을 얻습니다.
- 첫 탐험에서 안내문을 발견하며, 낮의 **연구 기록 조사**는 무작위 사건에 의존하지 않는 단서 경로입니다. 실험 절차서·명단·사고 기록을 토론에서 모두 공개하면 마지막 기록이 연결됩니다.
- 개인 목표는 진영 목표와 별개입니다. 달성하면 100점을 받고 기존 승패를 바꾸지 않습니다. 목표와 개인 단서는 다른 AI에게 자동 공개되지 않습니다.
- 사건 선택은 물자·체력·관계·정보 공유·후속 사건에 반영됩니다. 발전기 분해로 후속 문 개방 사건을 막거나, 동료에게 조사를 맡겨 정보 공개 여부를 결정하게 할 수 있습니다.
- **미스터리 도감**은 완료한 게임에서 발견한 기록·사건·장소·목표·엔딩을 별도 저장합니다. 진행 중인 게임의 미완료 기록을 수집하지 않으며 과거 도감은 새 AI에게 주어지지 않습니다.
- 씨앗 숫자가 같아도 선택·난이도·게임 버전이 달라지면 이후 결과가 달라집니다. 모든 이야기를 보기 위해 3일을 강제하지 않으며 기존 탈출 조건을 달성하면 즉시 끝납니다.

## 직업과 자원

6명에게 공작원 1명, 탐험가·의사·기술자·조사관 각 1명, 생존자 직업 중 무작위 중복 1명을 섞어 배정합니다. 인간도 모든 역할을 받을 수 있습니다.

| 직업 | 실제 효과 |
| --- | --- |
| 탐험가 | 탐험 성공 확률 +15%p, 정글 부상 확률 60% 감소, 야간 탐험 가능 |
| 의사 | 의약품 1개로 체력 45 회복; 다른 직업은 25 회복 |
| 기술자 | 부품 1개로 수리도 +3; 다른 직업은 부품 2개로 +2. 연구소·통신탑 탐험 성공률 +10%p |
| 조사관 | 탐험 단서 확률 +25%p. 밤에 실제 방해 행동의 흔적을 불확실하게 조사 |
| 공작원 | 정상 탐험 가능. 낮·밤 물자 최대 3개 은닉 또는 시설 수리도 최대 4 파괴 |

조사는 역할을 읽어 알려 주지 않습니다. 당일 실제 은닉·파괴 이력이 있으면 흔적 판정 확률 75%, 없으면 20%이며 오해와 미탐지가 가능합니다. 조사 결과와 발견한 단서는 개인 정보이며 공개 발언을 선택해야 공유됩니다.

초기 공동 자원은 **식량 12 / 식수 12 / 의약품 2 / 부품 2**입니다. 하루 끝에 활동 중 인원당 식량과 식수 각 1개를 정확히 한 번 소비합니다. 부족분은 공평하게 나누며 전원에게 `ceil(식량부족비율 × 20) + ceil(식수부족비율 × 30)`만큼 체력 피해를 적용합니다. 자원은 0 미만으로 내려가지 않습니다. 의약품·부품이 없으면 해당 행동을 숨기고 보급·휴식으로 진행할 수 있습니다.

탐험은 지역별 자원, 성공·단서·부상 확률을 사용합니다. 보급 상자 특별 발견도 있습니다. 기존 8종 하루 종료 사건은 회귀 검증 모드에 보존하고, 일반 플레이에서는 새 선택형 사건을 사용합니다. 모든 밸런스의 기본값은 `js/config.js`에 모았습니다.

## 엔딩 우선순위

상태 전이 엔진이 아래 순서로 판정합니다. 역할 능력으로 시설이 완성되면 그 시점에 탈출하며 뒤의 방해 행동은 실행하지 않습니다.

1. **D · 생존 실패:** 활동 가능한 생존자가 없음. 추방자는 야영지의 활동 인원에서 제외됩니다.
2. **C · 공동체 붕괴:** 활동 가능한 생존자 진영이 없고 공작원만 남음.
3. **B · 색출 후 구조:** 공작원이 투표로 추방되고, 그날 밤 배급 정산 이후 생존자 진영이 남아 있음. 비상 무전 구조가 자동 성립합니다.
4. **A · 탈출:** 통신탑 수리도 18 또는 보트 수리도 14 완성.
5. **C · 시간 초과:** 3일차 밤 정산 후에도 위 조건으로 끝나지 못함. 공작원 진영 승리.

공작원 진영의 승리는 생존 여부와 별개인 진영 판정입니다. 화면은 진영의 승패와 자신의 생존·추방·사망 상태를 따로 표시합니다. 종료 후 게임 행동은 차단되며 결과·기록 확인과 새 기록 시작만 가능합니다.

기본 승패 판정 뒤 공개한 진실, 확보한 연구 자료, 활동 인원, 공작원의 의혹 수준에 따라 9종 세부 결말을 선택합니다. 종료 화면에는 승리 진영·생존/추방 인물·공작원·목표 결과·사건·단서·미발견 수가 표시됩니다.

## AI와 정보 분리

`state.js`가 전체 상태와 실제 사실을 관리합니다. 인물 공개 데이터는 `players`, 비밀 직업·목표·단서·관계·행동 이력은 `secrets[id]`에 분리합니다. `viewFor(state, id)`는 공개 데이터와 해당 인물의 개인 정보만 복사해 반환합니다. `ai.js`와 `ui.js`는 이 제한된 뷰만 받습니다.

AI는 물자 부족, 부상, 부품, 자신의 역할, 자신의 단서·의심·신뢰, 성격을 고려합니다. 논리형·신중형은 투표 기준이 높고 공격형은 낮습니다. 협력·치료·공유는 신뢰에, 관찰한 단서와 전달받은 주장에는 의심에 영향을 줍니다. 낮은 신뢰만으로 역할을 확정하지 않습니다. 개별 기억은 사건 시간·장소·인물·출처·직접 관찰 여부·신뢰도·판단 수정 이력을 포함합니다. 같은 시점의 직접 증거가 있어야 발언 모순을 확정하며, 상충하는 전언만으로 거짓말을 확정하지 않습니다. 동선은 한 단계당 한 곳으로 모델링합니다. 개인별 신뢰와 의심은 각각 45~55/17~23에서 무작위로 시작하며 0~100 범위에서 독립적으로 변합니다.

공작원의 비밀 행동자와 개인 결과는 공개 로그에서 제외하고, 물자·시설 손상 결과만 단계 말에 묶어 알립니다. 로컬 싱글플레이이므로 개발자 도구나 저장 파일 자체에서 모든 비밀을 완벽히 숨기는 보안 구조는 아닙니다.

인물 카드를 펼치면 **내가 알고 있는** 관계 변화·행동·발언을 볼 수 있습니다. 다른 AI의 숨겨진 관계 수치와 거짓말 의도는 노출하지 않습니다. 난이도는 시작 시 선택하며, 보통이 기준입니다. 초급/고급은 관찰 주의력, 기억 활용 기간, 관계 비중, 판단 오차와 마지막 날 계획도 바꾸며 정보 접근 권한은 동일합니다.

- 매 선택과 행동 후 `island-mystery.save.v4`에 자동 저장합니다.
- 역할·체력·자원·현재 단계·행동 완료 상태·단서·관계·로그·엔딩·난수 상태와 사건 선택 대기·개인 목표·장소·분기를 포함하므로 이어하기 후 AI나 결과를 다시 굴리지 않습니다.
- Phase 2의 `island-mystery.save.v2`와 Phase 3의 `island-mystery.save.v3`는 형식을 검증하고 역할·자원·단계·로그·관계·난수 상태를 보존해 이어갑니다. 원본 키는 덮어쓰지 않습니다. 새 개인 목표를 배정하되 이전 게임의 난수 상태와 관계를 보존합니다. 과거에 저장하지 않았던 동선·관찰은 만들어내지 않으며 새 기억은 이후 행동부터 쌓습니다.
- Phase 1의 `island-mystery.save.v1`은 삭제하거나 덮어쓰지 않습니다. 해당 기록을 발견하면 새 규칙으로 새 게임을 시작하라는 안내를 표시합니다.
- 손상된 새 버전 기록은 읽지 않고, 사용자가 새 기록 교체를 확인할 때만 덮어씁니다.
- 저장소 차단·용량 부족 시 경고를 표시하고 메모리에서 플레이를 계속합니다. 이 경우 창을 닫으면 저장되지 않은 진행을 잃습니다.
- 브라우저·프로필·접속 주소·로컬 파일 경로가 바뀌면 저장 공간도 달라질 수 있습니다. 여러 탭 실시간 동기화는 지원하지 않습니다.

화면·소리 설정은 `island-mystery.settings.v1`에 저장하며 현재 게임과 도감을 변경하지 않습니다.

도감은 `island-mystery.codex.v1`에 별도 저장됩니다. 같은 완료 기록의 중복 적립을 막으며 손상된 도감은 보존하고 읽기 실패를 알립니다. 수집 실행 ID 보관 한도는 최근 1,000회입니다.

## 테스트와 제한

```sh
npm test
npm run test:simulation
```

단위·통합 테스트와 300회 시뮬레이션은 Node.js 22 이상에서 별도 패키지 설치 없이 실행됩니다. 검증 환경은 Node.js 24.14.0입니다. 실제 Chrome 자동 검증은 개발 의존성 설치와 설치된 Chrome이 필요합니다.

```sh
npm ci
npm run dev
# 다른 터미널에서
npm run test:browser
# Firefox를 포함한 설정·음향·실패 대체 처리 검사
npx playwright install firefox
npm run test:browser:features
npm run test:strategies
```

브라우저 테스트는 설치된 Chrome의 독립적인 임시 프로필을 사용합니다. 사용자 브라우저 저장을 건드리지 않습니다. 다른 설치 채널은 `TEST_BROWSER_CHANNEL`로 지정할 수 있으나 전체 완주는 Chrome, 주요 화면·오디오·설정 검사는 Chrome와 Playwright Firefox에서 수행했습니다. 브라우저 테스트 의존성은 게임 실행에 필요하지 않습니다.

최종 결과: [Phase 6 보고서](docs/PHASE6-REPORT.md), [변경 전 진단](docs/PHASE6-BASELINE.md), [300회 고정 조건 비교](docs/phase6-after.json), [150회 전략 비교](docs/phase6-strategies.json), [브라우저 A~E](docs/phase6-browser-results.json), [Chrome·Firefox 기능 검사](docs/phase6-browser-features.json). 시뮬레이션의 원본 CSV와 시드 목록도 저장소에 있습니다. 과거 보고서와 백업은 보존합니다.

AI는 자유 입력 언어 모델이 아닌 규칙 기반입니다. 이번 비교는 정해진 행동 정책의 결과이며 인간 승률이나 재미 평가가 아닙니다. 생존자 진영 우세와 의료품 잉여가 남아 있습니다. AI 추리 수준이 높으면 동료와 상대 모두 더 정확하게 판단하므로 인간의 역할에 따라 체감 난이도가 달라집니다. Safari·모바일 실기기와 실제 초보자의 플레이 시간은 측정하지 않았습니다.

첫 실행 안내는 건너뛸 수 있고, 설정에서 행동 결과를 접거나 모든 연출을 줄일 수 있습니다. 주요 밸런스 수치는 `js/config.js`에서 관리합니다. 사건 고유 효과와 숨겨진 장소 보상은 콘텐츠 데이터인 `js/story-data.js`에 유지합니다. 저장 형식은 v4를 유지하고 이전 v2/v3 원본은 마이그레이션 시 보존합니다.
